Real-time network intrusion detection using LSTM and Random Forest.

MSc Computer Science research project focused on AI-based network traffic analysis.

## Stack

Python, TensorFlow/Keras, Scikit-learn, Scapy, Pandas, NumPy, Streamlit.

## Features

* LSTM + Random Forest detection
* PCAP analysis and feature extraction
* Real-time traffic monitoring
* Anomaly scoring
* Traffic simulation

## Results

| Metric    |  Score |
| --------- | -----: |
| Accuracy  | 99.20% |
| Precision |  93.7% |
| Recall    |  93.1% |
| F1        |  93.4% |

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
